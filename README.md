This is a simple mini game that asks for the foundation or independence centuries of some cities, towns and villages in Spain.
This is the first project I've done since I've started the CS50x Harvard course.
To run the game just type in the terminal the following commands in order:
cd ~/Desktop/guess_the_year
make guess_the_year
./guess_the_year
In case of an error type this: make guess_the_year LDLIBS=-lcs50
Have fun!
